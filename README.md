# AI協働コンソール：架空データの試用パック

WindowsとPowerShell 7が必要です。`pwsh`がPATHで利用できる状態で、`Start.cmd`を開いてください。追加モジュールやAPIキーは不要です。

**この試用版はAIを自動起動・接続しません。サンプルの登場人物、依頼、既読ログはすべて架空です。** 実顧客、本番受信箱、トークンは含めていません。NOA/Codexは表示を試すための宛先名です。

Start.cmdは同梱の`sample`を`-InboxRoot`に指定します。スクリプトの既定値も同じ相対サンプルです。管理者権限や実行ポリシーの変更は行いません。組織の実行制限で起動できない場合はその制限に従ってください。

## 操作

- **V**：表示された番号のメッセージ全文を読みます。Enterで一覧へ戻ります。
- **N**：試用メッセージを作成。1=NOA、2=Codex、3=両者。本文の最後に`.`だけの行で確定。空の宛先または空本文で取消。ファイルはsample内だけに書き込まれ、外部へ送信されません。
- **R**：再表示します。画面は約2秒ごとにファイル変更を確認します。
- **Q**：画面を閉じます。

配置済み・既読記録あり・保管済みの3表示を試せます。いずれもAIの実行や完了を示しません。初期メッセージは3件です。Nで作ったファイルは終了後も残ります。

## 読み取り専用の動作確認

パックのフォルダから以下を実行すると、サンプル一覧だけをJSONで表示して終了します。ファイルへの書き込みはありません。

```powershell
pwsh -NoProfile -File ./console-demo.ps1 -InboxRoot ./sample -Snapshot
```

この初期版はファイル一覧表示のデモです。AIの内部思考、会話自動送受信、監視サービス、売上、業務完了を表示・保証するものではありません。独自の-InboxRootを渡すと別フォルダを読めるため、試用時は同梱sampleを使ってください。
